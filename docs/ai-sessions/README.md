# Historial de sesiones de IA

Esta carpeta conserva resúmenes o exportaciones saneadas de las sesiones de IA por historia o defecto (`<story-id>-<slug>.md` o `BUG-NN-<slug>.md`), enlazadas en cada Pull Request.

## Regla de saneamiento obligatorio

Antes de versionar cualquier archivo en esta carpeta:

- Elimina secretos, tokens, cookies, contraseñas y valores de `.env`.
- Elimina o parafrasea cualquier texto confidencial del enunciado o de `docs/_private/`.
