# Gestión de defectos

En fase de corrección de defectos, cada bug se trabaja en una rama `bugfix/BUG-NN-<slug>` siguiendo **TDD** (prueba de regresión que falla → fix en la causa raíz → prueba en verde) y se documenta aquí o en un archivo `BUG-NN.md` con:

1. **Síntoma y pasos de reproducción**
2. **Causa raíz**
3. **Solución aplicada**
4. **Prueba de regresión y evidencia de validación**
